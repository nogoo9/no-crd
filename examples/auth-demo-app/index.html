Header Injection Mode

The Gateway intercepts all requests routed to the workspace. If `inject-headers` is set in the auth mode, it injects the identity headers (`X-User-Sub`, `X-User-Roles`, `X-Workspace-Jwt`, and `Authorization`) directly into the proxied requests forwarded to this pod container backend.

Proxy-Level Transparent Refresh & Expiry Simulation

The gateway proxy transparently refreshes expired access tokens in the background using the encrypted nocr_refresh cookie (BFF pattern).
How to test transparent refresh:
1. Open your browser's DevTools (F12) → Application/Storage → Cookies.
2. Delete the nocr_sess and nocr_token cookies, but keep nocr_refresh.
3. Click "Fetch Headers" or "Fetch Token". You will see they load successfully, and fresh cookies are set.
How to test interactive redirect fallback:
1. Click "Full Logout" below. This calls the gateway's logout handler to wipe all cookies (including nocr_refresh).
2. Click "Fetch Headers". Since no credentials exist, you will be redirected to the gateway login page.

Integration Code Patterns

1. Backend / Header Injection (Node.js/Express)

When inject-headers is active, read user identity and token directly from request headers. If a request is unauthenticated, redirect or return 401.

// In your backend server:
app.get('/api/resource', (req, res) => {
  const userSub = req.headers['x-user-sub'];
  const token = req.headers['x-workspace-jwt'] || req.headers['authorization']?.split(' ')[1];

  if (!userSub) {
    // Session expired or unauthenticated request
    return res.status(401).json({ error: 'Session expired' });
  }

  // Use the token to fetch external resources or database
  res.json({ message: `Hello User ${userSub}` });
});

2. Proactive Frontend Token Refresh (JavaScript)

Normally, the gateway proxy refreshes tokens silently at the server layer. However, if your frontend SPA wants to proactively refresh its token in memory without any page redirection, it can call the _auth/refresh endpoint:

// Refresh token explicitly:
async function refreshToken() {
  const res = await fetch('./_auth/refresh', { method: 'POST' });
  if (!res.ok) {
    throw new Error('Refresh failed (interactive re-login required)');
  }
  const data = await res.json();
  return data.token; // Returns fresh JWT
}
